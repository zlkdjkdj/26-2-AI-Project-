# 웹 MVP 검증 기록

2026-10-01, Linux / Python 3.14 / Node 24 환경.

- 백엔드 69개 테스트 통과, 47.23초. Starlette TestClient의 httpx 사용 관련 경고 1개.
- 실제 YOLO + Grounding DINO ONNX 추론, 위험 DB, 점수 보류, SQLite 마이그레이션, Gemini 응답 및 실패 처리 검증.
- 전기설비 모델은 추가 API 없이 서버 CPU에서 실행. 일반 모델에 없는 전선·콘센트·멀티탭 클래스 보완.
- 사용자 첨부 사진 회귀 테스트: 전선 1개, 콘센트 2개, 멀티탭 오분류 없음. 개인 사진은 저장소 테스트 fixture에 복사하지 않음. ELECTRICAL_REGRESSION_IMAGE로 선택적 검증.
- 공개 CC0 멀티탭 fixture 실제 추론, 빈 단색 사진 오탐 방지, 겹친 종류 정리와 분류 불확실성 표시 검증. 모델 누락 시 503, Mock 대체 및 불완전 기록 저장 없음.
- 브라우저에서 첨부 사진 업로드 → 거실 직접 선택 → 실제 API 분석 성공: 객체 4개(전선·TV·콘센트 2개), 참고 점수 84, 위치 박스·전선 개선 피드백·실제 Gemini 안내 표시. 자동 공간 추정은 해당 사진에서 판단 불가를 표시했으며 거실을 직접 선택함.
- 당시 위험규칙 1,220개. 규칙 개수는 모델 클래스나 탐지 정확도를 의미하지 않음.
- 직접 점검 확인·메모 저장, 별도 종합 참고 점수, 고위험 우선 가이드와 완료 상태, HTML 보고서 escaping 및 출력 검증.
- 브라우저에서 직접 점검 저장, 인테리어 가이드 완료, 서버 재시작 후 이력 검색 및 상태 유지 확인.
- 생활 확인 동의·소유자/보호자 권한 분리·위치 접근 제한·중지 시 위치 제거·연결 끊김과 웹 미활동 구분·시간대·알림 중복 방지 테스트. 실제 GPS 권한 및 위치 수집은 브라우저 검증하지 않음.
- 프론트 npm run build 성공. 390px 화면에서 가로 넘침 없음.
- Vite 동일 출처 /api 및 /uploads 프록시, 서버 관리 스크립트 상태 정상.

실행은 React 웹 + 개발 PC FastAPI/Uvicorn + SQLite 파일 DB이며 Flutter/APK는 아직 생성하지 않았습니다. AI 추론, 위험 판정, 점수, Gemini 호출은 서버에서 수행하며 향후 APK도 동일 API를 사용합니다. 일반 점검 API는 단일 사용자이며 공개 배포 전 인증·기록 접근 권한·사진 비공개 저장·운영 서버 배포가 필요합니다.

전기설비 추론은 테스트 CPU에서 약 16~25초입니다. 소수 회귀 사진의 통과는 일반 정확도 지표가 아닙니다. 다양한 양성·음성 사진과 라벨로 종류별 precision/recall·IoU 및 부하를 평가해야 합니다. 물기·과부하·실제 높이·통로 폭은 확정하지 않습니다. 점수는 사진에서 관찰한 항목과 위험 규칙의 참고값이며 탐지 누락은 안전을 의미하지 않습니다.

웹 생활 확인은 동의 후 해당 웹 화면의 클릭/키 입력과 연결만 관찰합니다. 앱 종료 후 지속 관찰·휴대폰 전체 활동·문자/푸시 전송은 구현하지 않았습니다. 실제 Android 백그라운드 기능은 모바일 단계에서 별도 개발합니다.

## 공개 참고 자료 및 저부하 보조 분류기

- CC BY 4.0 공개 데이터셋 Zenodo 18835199 다운로드, 고정 MD5 검증·안전한 압축 해제·3GB 제한 적용. 사진 3,668개, 라벨 4,994개, 이미지 파일 약 196MB, 압축·라벨·DB·보조 산출물 포함 약 379MB.
- SQLite 참고 카탈로그에 출처·저자·라이선스·경로·SHA256·원본 그룹·정규화 위치 라벨 저장. 재인덱싱 후 사진 수 3,668로 유지. 서비스 위험 DB와 구분.
- 사용자 허용에 따른 보조 학습: 540개 공개 객체 부분, 64×64 특징, CPU 1 스레드, 60초 실행 제한. 실제 7.22초. 대형 모델 재학습·PyTorch/GPU 설치·예약 작업 없음.
- 원본 이름 그룹과 정확한 파일 해시 중복을 함께 묶어 425개 학습 / 55개 검증 / 60개 테스트. 두 분할 간 이름 그룹·정확한 해시 중복 0. 근접 중복 전체를 제거했다는 의미는 아님.
- 테스트 부분 분류 정확도 76.67%, macro F1 0.7669. 전체 이미지 객체 탐지 지표가 아님. 검증의 분류 점수 0.9 이상인 23개 중 정확도 95.65%였으나 표본이 작고 일반 정확도 보장이 아님.
- 모델 12,849 bytes. 기존 콘센트/멀티탭 박스에서 강한 불일치에 종류 확인 필요를 추가하며, 객체·위치·기존 위험 판정은 제거/교체하지 않음. 실제 사용자 사진의 작은 콘센트 부분과 별도 멀티탭 부분에서는 보조 점수가 기준 미만으로 기존 결과 유지. 개인 사진은 학습에 사용하지 않음.
- 신규 보조 검증 테스트 5개 통과. 손상·미설치 가중치에서도 기존 결과 유지, 낮은 점수로 모호함을 새로 만들지 않음, 강한 불일치에만 확인 표시, 원본 중복 그룹 분리 검사. 관련 기존 빠른 테스트를 포함한 7개도 통과.
- 서버 재시작 후 /api/health reference_verifier 준비 상태 확인. 전기설비 ONNX 기본 CPU 스레드를 4→2로 제한. 기존 전체 69개 실제 추론 테스트는 보조 모델 연결 전 결과이며, 이후 전체를 반복 실행하지 않음.
