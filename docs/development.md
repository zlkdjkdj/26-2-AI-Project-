## 준비 환경

Node.js 20.19 이상 또는 22.12 이상과 Android 개발 환경이 필요합니다. Expo Go에는 프로젝트의 WebRTC와 ONNX 네이티브 모듈이 포함되지 않으므로 자체 Android 개발·릴리스 빌드를 사용합니다.

```bash
cd mobile
npm ci
npm test
npm run lint
npm run typecheck
```

설치 과정의 `postinstall`이 WebRTC 패치를 적용합니다. Android 빌드에는 SDK와 Java가 필요하며, 앱 서명키와 기기 데이터는 Git에 포함하지 않습니다. 모바일 위험 규칙은 `mobile/src/offlineRules.js`에 포함되어 있습니다.

## 사진 점검

최초 사용 시 사용자가 가구 모델 약 45MB와 선택적 전기 실험 모델 약 204MB를 내려받습니다. 앱은 다운로드의 SHA-256을 검증하고 모델을 기기 전용 저장소에 보관합니다. 다운로드 후 기기 내 분석은 네트워크 없이 사용할 수 있습니다. 추론 런타임은 기본 앱에 포함됩니다.

추가 모델이 켜져 있으면 기존 전기·바닥 후보 외에 선풍기·의자·책상·테이블에 대한 개별 질의를 추가합니다. 휴대폰 기종에 따라 분석 시간이 늘어날 수 있으며 분류 충돌은 종류 확인 항목으로 표시합니다. 추가 모델이 없거나 꺼져 있으면 기존 기본 모델만 사용합니다. 기본 결과는 추가 모델 실행 중 임시 결과로 먼저 표시하며, 최종 점수와 표시 항목은 달라질 수 있습니다.

메모리와 CPU 조건을 만족하는 기기에서는 기본 모델과 추가 모델을 병렬 실행하고, 추가 모델의 가구 확인도 최대 두 작업으로 병렬 처리합니다. 조건을 만족하지 않으면 순차 실행합니다. 모델 입력 텐서를 재사용하며, 실제 소요 시간과 속도 향상 폭은 기기·사진·사용 가능한 메모리에 따라 달라집니다.

RAM 5GiB 미만 기기에서는 전기 실험 모델을 제한합니다. 사진 기반 위험 후보와 점수는 안전 인증이 아니며, 전기설비 탐지의 오탐·미탐과 기기별 실행 성능은 추가 검증이 필요합니다.

모델과 라이브러리의 사용·재배포 라이선스를 확인하세요. 현재 YOLOv8s 가중치 메타데이터에는 AGPL-3.0이 명시되어 있습니다.
