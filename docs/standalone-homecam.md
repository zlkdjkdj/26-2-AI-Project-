# Android 독립 홈캠 안내

## 준비

촬영용과 모니터링용 Android 휴대폰에 앱과 Tailscale을 설치하고 같은 Tailnet에 연결합니다. 서로 다른 Wi-Fi나 모바일 데이터여도 Tailnet에 연결돼 있으면 사용할 수 있습니다. 기기 간 홈캠 영상에는 별도의 PC가 필요하지 않습니다.

## 연결

1. 촬영 기기에서 **홈캠 → 촬영용 공기계**를 선택하고 등록 QR을 만듭니다.
2. 모니터링 기기에서 **홈캠 → 모니터링 휴대폰**을 선택하고 QR을 스캔합니다.
3. 촬영 기기에서 촬영을 시작하고 모니터링 기기에서 영상을 엽니다. 촬영 화면에서 전면·후면 카메라를 전환할 수 있습니다.
4. 촬영용 기기는 충전 상태로 두고 앱과 화면을 켜 둡니다. 화면이 잠기거나 앱이 백그라운드로 이동하면 촬영이 중지됩니다.

기기 등록을 해제하려면 촬영 기기의 등록 해제 기능을 사용하세요. 영상은 녹화되지 않으며 음성, 백그라운드 촬영, 자동 낙상 감지·긴급 출동을 제공하지 않습니다.

## 사람 위치 표시

모니터링 기기에서 수신 영상을 기기 내 모델로 분석해 최대 한 명의 위치를 표시합니다. 신원 확인이나 낙상 판별이 아니며, 조명·가림·기기 성능에 따라 놓칠 수 있습니다.

## 연결이 안 될 때

두 기기의 Tailscale 연결과 촬영 시작 상태를 확인하세요. 등록 정보가 만료되었거나 해제되었다면 촬영 기기에서 새 QR을 만들어 다시 등록합니다. 자세한 보호 범위는 [보안 안내](../SECURITY.md)를 확인하세요.
